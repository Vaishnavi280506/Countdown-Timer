# Countdown Timer

A real-time countdown timer built with HTML, CSS, and JavaScript — tracks days, hours, minutes, and seconds to any target date.

## What I focused on

- Real-time date and time calculations using JavaScript's Date object
- Dynamic UI that updates every second without page refresh
- Clean display of days, hours, minutes, and seconds separately
- Handling edge cases like expired countdowns
